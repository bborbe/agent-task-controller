# Publish the task-age metric families and their accessors

<summary>
- Two new Prometheus series are declared in the metrics package: the oldest non-terminal task age and the non-terminal task count per age bucket.
- Both are gauges, because they are levels that must fall back to zero rather than counters that only grow.
- The oldest-age series is labelled by vault only; the bucket series is labelled by vault and by a bucket that is a closed set of exactly four values.
- The oldest-age doc comment states that the value is a level and names the seven-day alert threshold in seconds, so the alert rule in another repository has a written anchor.
- Every metric accessor in the codebase can reach the new series through the metrics interface, including the generated test fake.
- A package-level spec proves through the real registry that both families exist as gauges with exactly the frozen label names.
- Nothing is published at start-up: the series appear only once the scanner's recompute writes them, because the vault label value is not known to the metrics package.
</summary>

<objective>

This is the surface the age summary and the ticker in the following prompts write through; a rename after this point is a silent cross-repo break.
</objective>

   ```go
   // TaskOldestAgeSeconds is the age in seconds of the oldest dated non-terminal
   // task record, labelled by vault.
   //
   // It is a level, not a counter: the dedicated metrics ticker recomputes it and
   // Set()s the result, so the series falls back to 0 as soon as the last dated
   // record turns terminal. That is what makes a threshold expression alertable —
   // the alert rule in bborbe/nuke compares it against the 7-day threshold
   // `> 604800` seconds.
   var TaskOldestAgeSeconds = promauto.NewGaugeVec(
   	prometheus.GaugeOpts{
   		Name: "agent_controller_task_oldest_age_seconds",
   		Help: "Age in seconds of the oldest dated non-terminal task record, by vault.",
   	},
   	[]string{"vault"},
   )

   // TaskAgeBucketTasks is the number of non-terminal task records per age bucket,
   // labelled by vault and bucket.
   //
   // It is a level, not a counter: every successful recompute Set()s all four
   // bucket series, including the empty ones, so a scrape never sees a missing
   // series after a pass and each bucket reads 0 when it is empty.
   var TaskAgeBucketTasks = promauto.NewGaugeVec(
   	prometheus.GaugeOpts{
   		Name: "agent_controller_task_age_bucket_tasks",
   		Help: "Number of non-terminal task records per age bucket, by vault and bucket.",
   	},
   	[]string{"vault", "bucket"},
   )
   ```
   Names and label sets are frozen: `agent_controller_task_oldest_age_seconds` with exactly `[]string{"vault"}`, and `agent_controller_task_age_bucket_tasks` with exactly `[]string{"vault", "bucket"}`. No record identifier, path or filename may ever become a label.
